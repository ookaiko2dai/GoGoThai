# 🌴 GoGoThai (โกโกไทย) 🧳✨
> **แอปพลิเคชันเพื่อนเที่ยวไทยฉบับวัยรุ่น สไตล์มินิมอลน่ารัก (Cute Pastel & Soft Y2K Aesthetic)**  
> รวมครบทุกเรื่องเที่ยว: ปักหมุดที่เที่ยวลับ • คอมมูนิตี้หาเพื่อนหารทริป • ระบบแชร์ค่าใช้จ่ายทริปอัตโนมัติ • กล้องพร้อมฟิลเตอร์ Y2K และไดอารี่ความทรงจำ

---

## 📱 ภาพรวมแอปพลิเคชัน (Overview)

**GoGoThai** ได้รับการออกแบบมาเพื่อตอบโจทย์ไลฟ์สไตล์คนรุ่นใหม่ สายแบกเป้ สายคาเฟ่ฮอปปิ้ง และแก๊งเพื่อนที่ชอบออกเดินทางท่องเที่ยวในประเทศไทย โดยผสานฟังก์ชันการใช้งานที่ครบวงจรเข้ากับดีไซน์พาสเทลโทนอุ่น โค้งมน ละมุนตา สไตล์ฟองสบู่และปุ่มพิลล์ (Pill UI) ที่ใช้งานง่ายและสนุกสนาน

---

## ✨ ฟีเจอร์เด่น (Key Features)

### 1. 🏝️ สำรวจที่เที่ยว & ปักหมุดทริปยอดฮิต (Explore & Discover)
* **หมวดหมู่ที่เที่ยว:** ทะเลใส 🏝️, ภูเขา/ทะเลหมอก ⛰️, คาเฟ่ฮอปปิ้ง ☕, วันเดย์ทริปวัฒนธรรม 🏯, กางเต็นท์แคมป์ปิ้ง ⛺
* **Featured Slider:** การ์ดแนะนำทริปฮิตติดกระแส พร้อมคะแนนรีวิว ป้าย Vibe ประจำทริป และประมาณการงบประมาณต่อคน
* **รายละเอียดทริปครบครัน (Trip Detail):** แนะนำพิกัดถ่ายรูปมุมปัง 📸, ไฮไลท์ห้ามพลาด, ฤดูที่น่าไป และปุ่มกดบันทึกลงแพลน

### 2. 💬 คอมมูนิตี้ & ฟีดหาเพื่อนเที่ยว (Community & Travel Buddy)
* **Live Trip Stories (24 ชม.):** แถบสตอรี่สดของเพื่อนร่วมทาง พร้อมเปิดดูพรีวิวรูปภาพและ Vibe แบบเต็มจอ
* **ฟีดรีวิววัยรุ่น:** กดไลก์ ❤️, บันทึกโพสต์ 🔖, คอมเมนต์แลกเปลี่ยนข้อมูล 💬
* **Travel Buddy Finder:** ระบบปักหมุดหาเพื่อนร่วมทริปเพื่อช่วยหารค่าน้ำมันหรือค่าที่พัก (เช่น *"รับอีก 2 คน หารค่าน้ำมัน+ที่พัก"*)
* **สร้างโพสต์ง่ายๆ:** เลือกอิโมจิ Vibe ประจำตัว, ระบุพิกัด, ใส่งบประมาณ และแชร์ลงคอมมูนิตี้ได้ทันที

### 3. 🧾 ระบบแชร์ค่าใช้จ่ายทริป & PromptPay (Smart Bill Share)
* **Smart Budget Tracker:** ติดตามยอดใช้จ่ายรวมในทริปเทียบกับงบประมาณ พร้อมแถบแสดงเปอร์เซ็นต์ (Progress Bar)
* **คำนวณยอดใครจ่าย-ใครต้องโอนคืน:** สรุปยอดเงินของสมาชิกแต่ละคนในทริปอย่างแม่นยำอัตโนมัติ
* **เคลียร์บิล 1-Click ด้วย PromptPay:** กดปุ่มโอนเงินจะเปิดหน้า QR Code พร้อมเพย์ ระบุยอดเงินและเบอร์รับเงินของเพื่อนปลายทางทันที
* **บันทึกแยกหมวดหมู่:** ที่พัก, อาหาร, คาเฟ่, น้ำมัน/การเดินทาง, ค่ากิจกรรม พร้อมระบุผู้จ่ายและเลือกว่าหารกับใครบ้าง

### 4. 📸 สตูดิโอกล้อง & ไดอารี่ Vlog ความทรงจำ (Camera & Memories)
* **กล้องพร้อมฟิลเตอร์พรีเซ็ต:** สลับฟิลเตอร์สดสไตล์ Y2K และคาเฟ่ (*📸 Film Y2K, 🌅 Golden Sunset, ☕ Warm Cafe, 🌊 Teal Ocean, 🧋 Pastel Pink, 🌿 Mint Green*)
* **โหมดภาพนิ่ง & วิดีโอ Vlog:** รองรับทั้งการถ่ายรูปและอัดคลิปวิดีโอ พร้อมเส้นกริดช่วยจัดองค์ประกอบภาพ
* **Memories Gallery:** จัดเก็บภาพถ่ายและวิดีโอประทับใจเป็นไทม์ไลน์ พร้อมระบุฟิลเตอร์ที่ใช้และตกแต่งด้วยสติกเกอร์น่ารัก

### 5. 🛂 โปรไฟล์ & สมุดสะสมตราประทับ (Passport Stamps)
* **ระบบเหรียญตราความสำเร็จ:** ปลดล็อกตราประทับเมื่อพิชิตจุดเช็คอิน เช่น *นักล่าหมอกยอดดอย 🏔️*, *คาเฟ่ฮอปปิ้งตัวแม่ ☕*, *เจ้าสมุทรเกาะใต้ 🏝️*, *นักหารบิลมือโปร 🧾*
* แสดงสถานที่ที่บันทึกไว้เป็นรายการโปรด (Saved Favorites) และสถิติการเดินทาง

## 🎨 การออกแบบ & ดีไซน์ซิสเต็ม (Design System)

| หมวดหมู่ | รายละเอียด |
|---|---|
| **โทนสีหลัก (Primary)** | ส้มพีช Coral (`#FF6B6B`), พีชสว่าง (`#FF8E72`), พาสเทลชมพูอ่อน (`#FFE3E3`) |
| **โทนสีเสริม (Secondary)** | มินต์สดใส (`#4ECDC4`), ซันนี่เยลโลว์ (`#FFD166`), ลาเวนเดอร์ (`#9B5DE5`), สกายบลู (`#00BBF9`) |
| **พื้นหลัง (Background)** | ครีมอบอุ่นละมุนสายตา (`#FAF7F2`), การ์ดขาวบริสุทธิ์ (`#FFFFFF`) |
| **Typography** | [Google Fonts - Prompt](https://fonts.google.com/specimen/Prompt) (รองรับภาษาไทยสวยงามทันสมัย) |
| **UI Components** | รูปทรงโค้งมนเป็นพิเศษ (Border Radius 20–32px), Floating Pill Navigation Bar |

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

### 1. โคลน Repository
```bash
git clone https://github.com/ookaiko2dai/GoGoThai.git
cd GoGoThai
```

### 2. ดาวน์โหลด Dependencies
```bash
flutter pub get
```

### 3. รันโปรเจกต์
* **รันบน Web Browser (Chrome):**
  ```bash
  flutter run -d chrome
  ```
* **รันบน Android Emulator / อุปกรณ์จริง:**
  ```bash
  flutter run
  ```

### 4. การบิลด์ไฟล์ APK สำหรับ Android
```bash
flutter build apk --release
```
ไฟล์ APK จะถูกสร้างไว้ที่: `build/app/outputs/flutter-apk/app-release.apk`
